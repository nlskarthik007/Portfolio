## Featured Projects

* **EDITH (TinyML Voice Activator):** An on-device, low-latency keyword spotter built for ESP32 microcontrollers. Utilizes I2S microphones and quantized Depthwise Separable CNN models via TensorFlow Lite for Microcontrollers to process MFCC audio spectrograms. Developed as part of the Smart India Hackathon (SIH) 2026.
* **Autonomous B3B Buggy Navigation:** A robotics project leveraging ROS 2 and OpenCV. Implemented LIDAR-based obstacle avoidance, HSV color masking, and trajectory smoothing to maintain lanes and safely navigate around obstacles.
* **Smart Home Security System:** A comprehensive hardware network built on the Arduino Mega. Features EEPROM-based MFRC522 RFID access control and real-time environmental hazard detection using gas, flame, and water level sensors.
* **Full-Stack E-commerce Platform:** A responsive web application integrated with a Firebase Realtime Database for live order tracking. Deployed via Netlify with automated EmailJS workflows and managed using the Google Antigravity AI IDE.
